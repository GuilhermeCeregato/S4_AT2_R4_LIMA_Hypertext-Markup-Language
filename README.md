# Relatório — HTML e semântica

Nesta atividade, desenvolvi uma página para a loja fictícia PixelGear eSports Store, utilizando HTML e CSS.

A semântica HTML é importante porque ajuda a organizar o conteúdo da página e facilita a compreensão do código. Elementos como `header`, `main`, `section`, `article` e `footer` também ajudam leitores de tela e mecanismos de busca a entender a estrutura do site.

Aprendi a utilizar títulos, parágrafos, imagens com textos alternativos, comentários, metatags e formatações de texto. Também utilizei CSS para personalizar as cores, as fontes e a organização dos produtos.

A validação pelo W3C permite encontrar erros no código e verificar se o documento segue os padrões HTML. Esse processo ajuda a corrigir problemas e a desenvolver páginas mais organizadas e compatíveis com os navegadores.
